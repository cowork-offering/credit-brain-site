The functional journey · redesign options

Five ways to show a request moving through the brain.

The current "Follow any request through the brain" diagram is a flat 2D radial chart (the dated, clunky one with the bar-stack brain). Each option below keeps the same five-beat story — ask → the brain reasons → it reaches your systems as you → a human decides → it learns — but rebuilt in the holographic, dimensional language the rest of the case study now uses. Mocks are animated 2D concepts to pick a direction; the winner gets built properly.

1

Orrery of the Request

A holographic brain-core orrery where one request spirals in, lights the orbits, and feeds back.

Idea
A luminous holographic brain core sits at centre. Three tilted 3D orbital rings (a gyroscope/atom/Saturn) carry the Model, the Tools and the Data as glowing nodes; a wider, slower outer ring is Governance, rendered as a faint guarded perimeter rather than a hard box. A request enters as a bright mote from a small MCP harness pip at top, spirals inward, the core pulses, and light reaches out along the orbits to do the work, then returns to the core. The whole instrument rotates gently in 3D so it reads as a dimensional object, not a flat radial chart.
Motion
The five beats are a single continuous flight, not five separate scenes. (1) ASK: a bright mote detaches from the harness pip at top and a faint "authenticated as you" tag travels with it. (2) REASON: the mote spirals down into the core; the core inhales and pulses brighter, a precedent-retrieval shimmer ripples across it. (3) REACH: a filament of light shoots out along the orbital plane to the Tools/Data nodes (each lights as it is touched, "in place, no data moved") and returns. (4) DECIDE: the outer Governance ring flares and a small human-gate diamond on it brightens and holds — the loop visibly waits on the human, then releases. (5) LEARN: a return arc curls back into the core and the core settles one notch brighter than it started — the compounding loop. On scroll the rings rotate slowly (different speeds, like an orrery), tilt is fixed so depth stays legible, and the cycle repeats so a reader who lingers always sees the request flowing.
Fits because
It speaks the same language as the rest of the rebuilt case study: a single glowing violet object on near-black, built from particles and thin light, that lives in 3D and rotates slowly as you scroll. The orrery's tilted rings echo the 3D-tilted reference-architecture diagram and the helix's "alive, dimensional, holographic" feel, while the orbiting Model/Tools/Data nodes are the same five-tier vocabulary (Brain/Model/Tools/Data/Records + Governance) expressed as an instrument instead of a flat radial. It directly replaces the dated flat 2D radial: same information, now dimensional and luminous.
The 5 beats
Ask = the harness pip at top releasing an authenticated mote ("the brain acts as you" rides in as the user's own credential, seeing only what they see). Reason = the mote spiralling into the core and the core pulsing as it retrieves precedent and connects the deal. Reach = the filament running out along the orbit to the Tools and Data nodes and back, work done in place without moving data. Human decides = the Governance outer ring flaring and the human-gate diamond holding the loop until a person releases it — guarded and audited, human stays in control. Learns = the return arc folding back into a core that ends brighter than it began, the compounding loop made literal.
Strength
One memorable, premium hero object that carries all five beats in a single continuous flight and naturally loops; the orrery metaphor makes "it acts for you, a human still gates it, and it compounds" legible at a glance without labels-as-clutter.
Watch-out
Orbital motion plus 3D tilt plus a travelling mote can tip into busy or hypnotic; keep ring speeds slow and staggered, dim non-active orbits during each beat, and ensure the human-gate pause is unmistakable so the "human in control" beat doesn't get lost in the spin.
2

Lumen Descent

A request-mote falls through five floating glass lenses; the answer rises back up.

Idea
A single vertical column of light holds five thin, 3D-tilted holographic glass plates stacked in depth — one per beat: Ask, Reason + Retrieve, Reach your systems, Human decides, Learn. A bright violet "request" mote descends the column. As it crosses each plate, the plate ignites, refracts a spread of light, and reveals its label; a faint vertical seam (the authenticated identity) runs the whole spine so every plate inherits "acts as you." When the mote reaches the bottom plate it inverts into a warmer magenta "answer" mote that rises back up the same spine — and a soft ring at the top closes the compounding loop into the next descent.
Motion
Scroll-synced: scroll position drives the mote's Y down the column, so the request literally descends as the reader reads. Each plate has a one-shot "ignite + refract" (brightness pulse, edge-glow bloom, label fade-in) triggered the instant the mote's Y crosses it. At the Human-decides plate the descent briefly holds — a guardian ring pulses and a checkmark settles — signalling the human gate before release. At the bottom the mote flips hue to magenta and ascends as the answer; reaching the top it feeds a thin halo that brightens the spine for the next loop. The plates breathe with a very slow parallax tilt so the whole stack reads dimensional, never flat. In the autoplay mock, mote descent + per-plate ignite + answer ascent run on a continuous loop.
Fits because
It reuses the rest of the case study's vocabulary directly: the reference-architecture's stacked tiers become living glass lenses, the 3D-tilt/slow-rotation language becomes the plates' parallax tilt, and the violet-on-near-black holographic glow + refraction matches the DNA-helix hero. Where the helix is the structure, this is the same structure caught mid-flow — one organism, two views.
The 5 beats
The five plates ARE the five beats top-to-bottom. (1) THE ASK is the top plate where the mote is born and the identity spine lights — authenticate once, act as you. (2) THE BRAIN REASONS is the second plate, which refracts the widest spread (precedent retrieved, deal connected). (3) IT REACHES YOUR SYSTEMS is the third plate, whose refraction reaches sideways to faint system glyphs that stay in place — work done, data unmoved. (4) A HUMAN DECIDES is the fourth plate where the descent pauses behind a guardian ring + check — guarded, audited, human in the loop. (5) IT LEARNS is the bottom plate: the mote inverts to the answer and rises, leaving the spine brighter than before — every decision sharpens the next descent.
Strength
Reads instantly as both "stack" and "flow" — vertical descent maps perfectly to scroll, so the reader's own scrolling becomes the request moving through the brain, and the rise-back-up makes "it compounds" felt, not labelled.
Watch-out
Five stacked glassy plates risk visual mush at small sizes or low contrast; keep refraction restrained and labels crisp, or beats 2-3-4 blur together. The scroll-hold on the Human plate must be tuned so it feels deliberate, not janky/stuck.
3

Living Brain Stream

The same particle-hologram brain from the hero, with one request flowing through it as light.

Idea
A dense, slowly-drifting particle-hologram orb (the SAME material as the hero DNA helix) sits center-stage on near-black. A request enters from the left as a thin stream of violet particles, dissolves into the orb where it brightens and circulates, then a refined answer-stream leaves to the right. Tool-call filaments reach out from the orb to four faint system glyphs and pull particles back. A human gate sits on the answer path, and a thin loop curls from the answer back into the orb (it compounds).
Motion
A single comet of particles travels left-to-right across the whole piece on a ~9s loop, narrating the 5 beats in sequence: it streams in (ASK), swirls and densifies inside the orb which pulses brighter (REASON), filaments fire out to the system glyphs and particles return along them (REACH), the comet pauses at a diamond human-gate that blinks approval (DECIDE), then a faint tail curls back into the orb closing the loop (LEARN). The orb itself drifts/rotates continuously (slow particle orbit + breathing glow) so it reads alive even between request passes. Everything is sub-pixel restrained: streams are 1px particle trails, glow is soft, no hard edges.
Fits because
It is literally the hero's material reused — same particle-hologram motif, same violet-on-near-black glow, same gentle 3D drift/rotation as the rotating reference-architecture diagram. Maximum "this is the same brain" recognition: the thing reasoning here is visibly the thing in the hero helix. Flat radial SVG with straight lines and a stack-of-bars is replaced by volumetric particle light that belongs to the cinematic, dimensional language of the rest of the study.
The 5 beats
Beat 1 ASK: particle stream enters from the banker's harness glyph (top-left), authenticated once — it carries the user's identity color and the orb only ever lights the regions that stream touches (sees only what you can see). Beat 2 REASON: stream dissolves into the orb, particles densify and orbit, glow brightens (the owned orchestrator reasoning with the model, retrieving precedent). Beat 3 REACH: filaments extend from the orb to four faint system glyphs (core/docs/risk/records), particles run out and return — work happens in place, data never relocates, only light moves. Beat 4 DECIDE: the outbound answer-stream meets a diamond human-gate that must blink green before particles pass — guarded, audited, human in the decision. Beat 5 LEARN: a thin tail of the answer curls back into the orb, and the next pass starts marginally brighter — the compounding loop.
Strength
Strongest possible material continuity with the hero/helix — the brain you reasoned about IS the brain in the diagram — and motion alone tells the full request story without labels-as-clutter.
Watch-out
Particle systems can drift into "pretty noise" that obscures the 5 discrete beats; the build must keep the single traveling comet legible and the human-gate beat unmistakable, or the meaning dissolves into ambiance.
4

Living Network

The brain and your lending estate as one slowly-rotating holographic constellation, with the request lighting a path hub to nodes and back.

Idea
A glowing 3D node-link constellation suspended on near-black: the brain is a bright violet hub at center, the bank's agents, tools, systems, and records are satellite nodes arranged on two tilted orbital rings, light-edges connecting them. The whole network drifts in a slow 3D rotation like a living organism. A governance field shimmers as a faint elliptical halo around everything; the human-decision node is a distinct guarded node on the perimeter. The request travels as a bright pulse from hub out to the nodes and loops back, and the return arc re-enters the hub slightly brighter each cycle to read as compounding.
Motion
The constellation group rotates continuously and slowly on a tilted axis (about a 24s loop), so depth shifts and the rings precess like a real 3D object. Independently, a single bright request-pulse rides the edges in beat order: hub to ask-node, into the hub, out to a tool/system node, over to the human node (which flashes a guarded ring as it decides), then a brighter return edge folds back into the hub. The hub itself breathes a soft glow pulse synced to each loop, getting a touch brighter on re-entry to signal learning. Nodes twinkle subtly; the governance halo slowly shimmers its dash. As you scroll the case study, each scroll-beat would foreground one edge in turn (ask, reason, reach, decide, learn).
Fits because
It is literally a node-link network rotating in 3D space with holographic violet glow on near-black, which is the same dimensional, slowly-rotating, particle-light vocabulary as the DNA helix hero and the tilted reference-architecture diagram. It trades the flat radial SVG for real depth (orbital rings, perspective, rotation) and replaces the clunky bar-stack brain with a single luminous hub, so it sits naturally beside the rest.
The 5 beats
(1) THE ASK: the request pulse originates at the banker/harness node on the top ring and fires into the hub, authenticated once. (2) REASONS: the hub blooms and inner edges light as the brain reasons and retrieves precedent. (3) REACHES SYSTEMS: the pulse runs out along edges to the tool/system/data nodes, acting as the user, no data moved (edges carry light, nodes stay put). (4) HUMAN DECIDES: the pulse reaches the distinct guarded human node, which flashes its protective ring while the governance halo shimmers around the whole field. (5) LEARNS: a brighter return arc folds back into the hub, which pulses a notch brighter, closing a compounding loop.
Strength
A single living, rotating network is instantly legible to a banker (their estate is the constellation, the brain is the bright center) while feeling premium and cinematic, and the same scene cleanly carries all five beats by just lighting different edges.
Watch-out
Constellations drift toward clutter and the rotation can wash out beat clarity. Keep nodes few (6 to 8), label sparingly, and make sure only the active beat's edge is bright at any moment, or the 5-beat story blurs into a generic network animation.
5

Living Reference Architecture

Watch your request move through the very same brain the architects built.

Idea
The exact 5-tier reference diagram from the technical side — a tilted, glowing boundary box holding Brain / Model / Tools / Data / Records, with an MCP-client harness docked on top and a governance frame wrapping it all — but here it's alive: one banker request enters at the harness, cascades down tier by tier (each lighting as the request passes), the real work flares at Tools and Data, the answer rises back up, the governance frame pulses on every crossing, and a learn-loop arcs from the answer back into the Brain tier so the structure visibly compounds.
Motion
A request token drops from the MCP-client harness and descends through the five tiers in sequence; as it touches each tier, that tier's panel ignites violet and a thin scanline sweeps it, then dims. At Tools and Data the token splits into a brief flare (the work happening in place, no data moving out). The token then reverses, rising back up brightening tiers as it returns, and surfaces at the harness as a filled answer. On every tier the request crosses, the surrounding governance frame gives a single magenta pulse (guarded + audited). Finally a curved learn-arc travels from the answer back down into the Brain tier, depositing a soft spark that makes the whole stack breathe one notch brighter — the compounding loop. The entire assembly holds a gentle, continuous 3D y-axis tilt-sway so it reads dimensional, matching the rotating architecture elsewhere. As the reader scrolls, the 5 beats map to descent → reason → reach → human-decide → learn, so scroll position is literally the request's depth in the stack.
Fits because
It IS the holographic 3D-tilt language — same near-black canvas, violet glow filters, hairline panels, and the same slow 3D rotation/tilt the reference-architecture diagram already uses. By reusing the identical 5-tier boundary box (not a new metaphor), it inherits the dimensional, assembled-on-scroll feel and trades the flat radial SVG for a living, depth-tilted structure that belongs beside the DNA helix and the spec helix.
The 5 beats
Beat 1 THE ASK = the request token drops from the MCP-client harness on top (authenticated once, then acts as you). Beat 2 REASONS = it lights the Brain and Model tiers as it descends (orchestrator reasons with the model, retrieves precedent). Beat 3 REACHES = it flares at Tools and Data in place — work done as the user, data never leaves. Beat 4 HUMAN DECIDES = the governance frame pulses on every crossing and a human-gate glyph on the rising answer must clear before it surfaces (guarded, audited, human in the loop). Beat 5 LEARNS = the curved learn-arc carries the captured decision back into the Brain tier, brightening the whole stack one notch — it compounds.
Strength
Maximum recognition and reuse: the audience sees the very architecture diagram from the technical story come alive with their own request flowing through it, so "the brain acts as you, a human stays in control, it compounds" is shown structurally rather than asserted — and it costs zero new visual vocabulary.
Watch-out
Five stacked tiers plus a harness, a governance frame, a down-and-up token path and a learn-arc is a lot to read at once; if every element animates simultaneously it turns to noise. Mitigation: strictly sequence the motion (only one tier lit at a time), keep the tilt subtle, and let the governance pulse and learn-arc be quiet single events, not constant shimmer.
